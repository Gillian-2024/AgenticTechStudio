# Voice Beat Sync：配音先行，动作踩在词上

原则：**画面跟配音走，动作踩在词上**。配音节奏一旦定下，画面不再反过来塞配音。

## 1. 生成时间线

```bash
pip install edge-tts   # 另需 ffmpeg/ffprobe
python scripts/build_timeline.py <script.md> <out_dir> --voice zh-CN-XiaoyiNeural --rate +5%
```

- 剧本分镜表格式：`| # | 最短秒数 | 旁白 | 画面 |`。
- 镜头时长 = max(0.3s 起始静音 + 配音时长 + 0.5s 尾部留白, 最短秒数)。
- 输出 `timeline.json`：每个镜头有 `start/end/vo_start/vo_end/line/words`；`words` 是 `[{t, d, text}]`，`t` 为全片绝对时间（秒）。中文按单字给出。
- 输出 `voiceover.m4a`：所有句子按 `vo_start` 放好的整轨配音，直接用于合成。

## 2. 在动画里取节拍

页面内嵌 `timeline.json` 为常量 `TIMELINE`，并内联 `assets/voice-beats.js`（自包含页面不能引用外部文件时，把文件内容粘进 `<script>`）：

```js
const beats = VoiceBeats(TIMELINE);
const [t6, t5, t4, tStop] = beats.all(9, ["跳过6", "跳过5", "跳过4", "停在"]);
// 第一跳在念出「跳过6」时起跳，落地对准「6」
const u = beats.progress(t, t6 - 0.25, t6 + 0.35);
```

- `at(shot, 词, n)`：第 n 次念到该词的时刻；`all(shot, [词...])`：按顺序逐个往后找。
- 匹配基于拼接后的文字，多字词（「跳过」「停在」）可直接用。旁白里有空格（「跳过 6」）时，查询写成去空格的「跳过6」。
- 找不到会直接抛错。这是有意的：旁白改了而动画没跟上时，验收阶段立刻暴露。

## 3. 对齐规则

| 情况 | 做法 |
|---|---|
| 动作的结果对应一个词（「换！」） | 动作的**落点**（落地、到位）对准该词开始时刻 |
| 动作需要预备 | 预备从词前 0.2–0.3s 开始，起跳贴近词开始 |
| 一句里连续多个动作（「跳过 6，跳过 5，跳过 4」） | 每个动作各自对准自己的词，不平均切分 |
| 数字或高亮的变化 | 在念到该数字的瞬间点亮，提前不超过 0.1s |
| 字幕 | 只在 `vo_start`–`vo_end` 之间显示 |
| 镜头运动 | 不必踩词；在句子之间或停顿处完成，避免和动作抢注意力 |

## 4. 反模式

- 在动画代码里写死秒数，或把一句的时长平均切成几段（样片 01 v2 的做法，动作和念到的数字对不上）。
- 改了旁白却不重跑 `build_timeline.py`。
- 动作提前于对应的词超过 0.3s：观众会先看到结果、后听到解释。

## 5. 验收

1. 改旁白后已重跑时间线，页面内嵌的是新 `timeline.json`。
2. 对每个关键词截一帧（词开始时刻 +0.1s），画面正在发生对应动作。
3. 字幕窗口与 `vo_start/vo_end` 一致（`scripts/qa_check.js` 自动检查）。

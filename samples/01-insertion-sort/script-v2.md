# 样片 01 v2：插入排序——小老鼠排队

v1 的问题（2026-11-25 复盘）：动作只有平移、画面平、讲法平；配音机械，且先定画面再塞配音，节奏对不上。

v2 的改法：

- **配音先行**：先用 `zh-CN-XiaoyiNeural` 合成每句旁白，按实际时长排出时间线（`timeline.json`），画面跟着时间线走。
- **讲法**：开头给观众一个「你已经会了」的惊喜；1 和 3 各占一个镜头，3 逐个点名跳过谁；结尾点出「左边一直是排好的」。
- **动作与画面**：遵循 [动画质量规范](../../research/motion-quality-spec.md)。

- 排序数组：`[5, 2, 4, 6, 1, 3]`
- 「最短秒数」是该镜头动作需要的最少时间；实际时长 = max(配音时长 + 停顿, 最短秒数)。

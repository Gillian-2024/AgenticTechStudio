# 样片 01 v3：插入排序——小老鼠排队

v2 → v3 改动（按 `.claude/skills/concept-explainer` 审查）：

- **R3 从副本派生 / R1 对象贯穿**：镜头 3 扑克牌直接飞上去变成老鼠的数字牌（match-cut），牌和老鼠是同一套对象。
- **R6 颜色固定含义**：橙 = 正在插入的那只，绿 = 已排好，白 = 还没轮到。全片不挪用。
- **R7 先指再动**：每次交换前，先给两只老鼠描边，停半拍再跳。
- **R15 反直觉例子**：新增镜头 11，本来就排好的队伍一次都不用换，一下就结束。
- **R16 recap 复用原对象**：镜头 10 回放「已排好」区域从左向右变长，用的还是这排老鼠。
- **配音节拍**：每个动作踩在念到的词上（`.claude/skills/voice-beat-sync`）。
- **角色**：用 `assets/characters/mouse-rig.js`（`.claude/skills/character-rig`）。

- 排序数组：`[5, 2, 4, 6, 1, 3]`
- 「最短秒数」是该镜头动作需要的最少时间；实际时长 = max(配音时长 + 停顿, 最短秒数)。

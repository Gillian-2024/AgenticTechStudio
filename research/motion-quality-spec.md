# 动画质量规范（v1，2026-11-26）

动画 Agent 写代码时必须遵守，验收 Agent 按「验收清单」逐条检查。

来源：OpenDesign（commit `5fdcc3d`）的 `design-templates/hyperframes/`、`skills/motion-design/`，以及 vibe-motion 的 `disney-animation-rule-skill`。规则为摘要转述，括号内是出处。

## 1. 时间线

- 画面跟配音走：每个镜头的起止时间读 `timeline.json`，不在代码里写死秒数。
- 关键动作踩在词上：用 `timeline.json` 的逐字时间戳（`words`）对齐，不把一句平均切分。做法见 `.claude/skills/voice-beat-sync`。
- 每个镜头分三段：入场（前 30%）、停留（中间 40%，只留一个轻微的环境动效）、收束（后 30%）。（hyperframes motion-principles）
- 第一个动作延后 0.1–0.3 秒开始，不从镜头第 0 秒起。（同上）
- 最慢的镜头节奏至少是最快镜头的 3 倍慢；不要所有动作都用 0.4–0.5 秒。（同上）

## 2. 动作

- 角色动作分阶段：预备（下蹲）→ 起跳 → 越过 → 落地挤压 → 回弹稳住。挤压只出现在加速和落地附近，不持续存在。（Disney skill）
- 次级动作晚于主动作开始、晚于主动作停下：牌子比身体晚半拍，尾巴最后甩停。（Disney skill）
- 缓动方向：入场用 out，离场用 in，两个位置之间用 inOut；不对所有属性用同一个线性进度。（hyperframes、Disney skill）
- 快动作必须有预备和回落；有生命的东西走弧线，机械的东西走直线。（motion-design）
- 讲解时先让对象出现，再让它变化；关系变化时标签不消失。（motion-design）
- 全片有一个贯穿的对象（这里是那排小老鼠），避免变成一张张互不相关的字卡。（motion-design）

## 3. 镜头与转场

- 镜头之间必须有转场；转场本身就是离场，最后一个镜头除外。（hyperframes）
- 比较时推近到两只老鼠；连续交换时镜头跟随主角横移；镜头运动 0.9–1.8 秒，inOut。
- 转场带含义：交叉淡化表示「接着讲」，硬切表示「注意」。（hyperframes motion-principles）

## 4. 画面

- 每帧至少 3 层：背景（带 2–5 个缓慢呼吸的装饰物）、主体、强调元素。静止的装饰物显得死。（hyperframes house-style）
- 一个强调色；背景全片一致；不用纯黑纯白；不用全屏线性渐变（编码后有色带）。（house-style）
- 字号下限：标题 60px，正文 20px，数字标签 16px；数字用等宽数字。（house-style）
- 不要：渐变文字、全部居中堆叠、emoji 当图标、紫蓝渐变。（house-style、anti-ai-slop）

## 5. 确定性（渲染必需）

- 所有画面状态是时间的纯函数：`state = f(t)`；`window.seek(t)` 调用后停止自动播放，只渲染 t 时刻。
- 不用 `Date.now`、不用不带种子的随机数，不依赖上一帧的状态。
- 必须暴露 `window.__state(t)`，返回 t 时刻的业务状态（如 `{order:[...]}`），供验收程序核对。（样片 01 v2 漏了这条，导致首轮只能看图核对）

## 验收清单

验收 Agent 只抽查一轮，最多修一次（motion-design 的「有限验收」）：

1. 程序检查：每个镜头的数组状态与分镜一致；字幕与 `timeline.json` 的旁白一致；无控制台报错。
2. 截图检查：开头、每次交换的落地瞬间、结尾，共不超过 12 帧，必须真看图：有无遮挡、溢出、文字压住角色。
3. 动作检查：交换镜头截「预备、空中、落地」三帧，确认有下蹲、弧线和挤压。
4. 音画检查：每句旁白念到的数字出现时，画面上正在处理那个数字。
5. 判缺陷前先对照 `timeline.json`：截图落在镜头之间的转场里时，元素滑出画面属于正常离场，不算缺陷。（样片 01 v3 曾把转场误判为「队伍跑偏」）
6. 验收由动画 Agent 以外的角色执行，并截满清单要求的时刻，不只抽几帧。（样片 01 v2、v3 中，动画 Agent 自检都漏掉了缺陷）
